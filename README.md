# Course GitHub

Этот проект содержит решения различных проблем в рамках курса по Git и GitHub.

## Описание

Проект демонстрирует работу с Git, включая создание веток, слияния и управление версиями. Включает решения трех основных проблем.

## Структура проекта

- `main.py`: Основной код с решениями проблем
- `requirements.txt`: Список зависимостей
- `tests/`: Тесты для кода

## Установка

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/todmiv/course_github.git
   ```

2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

## Использование

Запустите основной скрипт:
```bash
python main.py
```

## Ветки

- `main`: Основная ветка
- `develop`: Ветка разработки
- `2-problem-1`: Решение проблемы 1
- `3-problem-2`: Решение проблемы 2
- `4-problem-3`: Решение проблемы 3
